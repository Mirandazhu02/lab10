# lab10

Lab 10 for STAT 159: a short analysis of the TidyTuesday *Languages of Africa*
dataset, published as a MyST website on GitHub Pages and pitched with RevealJS slides.

- **Question:** which country in Africa has the largest number of spoken languages? (`africa_languages.ipynb`)
- **Data:** `data/africa.csv`, from [TidyTuesday 2026-01-13](https://github.com/rfordatascience/tidytuesday/tree/main/data/2026/2026-01-13).
- **Website:** built with MyST and deployed to GitHub Pages (see `.github/workflows/deploy.yml`).
- **Slides:** `slides.qmd` → [slides.html](https://mirandazhu02.github.io/lab10/slides.html)
